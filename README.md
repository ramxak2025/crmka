# Noor Muslim — Исламское приложение

Мобильное приложение для мусульман на Flutter с FastAPI бекендом.

## Возможности

- **Время намаза** — точный расчёт 6 молитв на основе астрономических формул. Поддержка нескольких методов расчёта (ДУМР, MWL, Умм Аль-Кура и др.)
- **Компас Киблы** — определение направления к Каабе в Мекке с использованием формулы большого круга. Показывает расстояние до Мекки
- **Достоверные Хадисы** — коллекция хадисов из 6 основных сборников (Бухари, Муслим, Абу Дауд, Тирмизи, Насаи, Ибн Маджа) с переводом на русский
- **Коран** — 114 сур с арабским текстом, русским переводом, транслитерацией и тафсирами (ас-Саади, Ибн Касир, аль-Мунтахаб)

## Архитектура

### Flutter (Clean Architecture + Feature-First)

```
lib/
├── main.dart                          # Точка входа
├── core/
│   ├── theme/                         # Темы (светлая/тёмная)
│   ├── constants/                     # Константы API и намаза
│   ├── utils/                         # Калькуляторы (намаз, Кибла)
│   └── widgets/                       # Переиспользуемые виджеты
├── features/
│   ├── prayer_times/                  # Время намаза
│   │   └── presentation/
│   │       ├── providers/             # Riverpod провайдеры
│   │       └── screens/               # Экраны
│   ├── qibla/                         # Компас Киблы
│   ├── hadith/                        # Хадисы
│   └── quran/                         # Коран с тафсирами
├── models/                            # Модели данных

```

### Backend (FastAPI)

```
backend/
├── main.py                            # Точка входа сервера
├── app/
│   ├── routers/                       # Маршруты API
│   │   ├── quran_router.py            # Эндпоинты Корана
│   │   └── hadith_router.py           # Эндпоинты Хадисов

│   │   └── hadith_service.py          # Сервис Хадисов
│   └── data/                          # JSON файлы с данными
└── tests/
    └── test_api.py                    # Тесты API
```

## Запуск

### Backend

```bash
cd backend
pip install -r requirements.txt
python main.py
# API доступен на http://localhost:8000
# Документация: http://localhost:8000/docs
```

### Frontend (Flutter)

```bash
flutter pub get
flutter run
```

### Запуск тестов

```bash
# Тесты бекенда
cd backend
python -m pytest tests/ -v

# Тесты Flutter
flutter test
```

## API документация

### Коран

| Метод | Эндпоинт | Описание |
|-------|---------|----------|
| GET | `/api/v1/quran/surahs` | Список всех 114 сур |
| GET | `/api/v1/quran/surahs/{id}/ayahs` | Аяты конкретной суры |
| GET | `/api/v1/quran/tafsir/{surah}/{ayah}` | Тафсир аята |
| GET | `/api/v1/quran/search?q=...` | Поиск по тексту |

### Хадисы

| Метод | Эндпоинт | Описание |
|-------|---------|----------|
| GET | `/api/v1/hadith/collections` | Список сборников |
| GET | `/api/v1/hadith/collections/{id}` | Хадисы из сборника |
| GET | `/api/v1/hadith/random` | Случайный хадис |
| GET | `/api/v1/hadith/{id}` | Хадис по ID |
| GET | `/api/v1/hadith/search?q=...` | Поиск хадисов |

## Дизайн

Приложение использует **Material 3** с исламской цветовой палитрой:

- **Основной** — исламский зелёный (#1B8A6B)
- **Акцентный** — золотой (#D4A843), как купола мечетей
- **Дополнительный** — глубокий бирюзовый (#0D5C63)
- **Фон** — тёмно-синий (#0A1628)

По умолчанию включена тёмная тема.

## Методы расчёта намаза

| Метод | Фаджр | Иша | Использование |
|-------|-------|-----|--------------|
| Россия | 15° | 15° | Россия и СНГ |
| ДУМР | 16° | 15° | Духовное управление |
| MWL | 18° | 17° | Мировая лига |
| Египетский | 19.5° | 17.5° | Египет |
| Умм Аль-Кура | 18.5° | 90 мин | Саудовская Аравия |
| ISNA | 15° | 15° | Северная Америка |
